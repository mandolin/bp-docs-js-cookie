# Security Policy

This repository is an HIA documentation-engineering derivative. The version table below
describes support for the upstream js-cookie runtime only; it does not define support for
this repository's documentation tooling or Pages workflow.

本仓是 HIA 文档化工程衍生仓。下方版本表仅说明上游 js-cookie runtime 的支持状态，不定义本仓文档工具或 Pages workflow 的支持周期。

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

The version table applies to the upstream js-cookie runtime only. For a runtime vulnerability,
follow the [upstream js-cookie security policy](https://github.com/js-cookie/js-cookie/security/policy)
and report privately to the upstream maintainers.

For a vulnerability in HIA-owned documentation tooling, generated-site handling, or workflows,
use the Security tab and private vulnerability reporting for this repository when available.
Do not post exploitable details in public issues. If private reporting is unavailable, contact
the repository maintainers privately before sharing technical details.

上表仅适用于上游 js-cookie runtime。runtime 漏洞请遵循
[js-cookie 上游安全政策](https://github.com/js-cookie/js-cookie/security/policy)，并私下报告给上游维护者。
HIA 文档工具、生成站点处理或 workflow 漏洞，请在本仓 GitHub Security 页面启用私有漏洞报告时通过该渠道提交；不要在公开
issue 发布可利用细节。若私有报告入口不可用，请先通过私下渠道联系本仓维护者，再分享技术细节。
