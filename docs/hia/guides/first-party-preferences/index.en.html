Primary journey

Complete the base integration in five steps

  1. 1
    Limit purpose and fields

    Keep fixed language and theme enums out of identity, session, consent, and analytics data.

  2. 2
    Read, then validate

    Invalid or damaged values take the default branch; validate each field independently.

  3. 3
    Update the current page first

    Apply the visitor's choice now; cookie persistence is best effort.

  4. 4
    Keep a failure path

    Reading remains available after a blocked write, expiry, or user cleanup.

  5. 5
    Support reset and migration

    Reuse the original scope when removing; migrate old path/domain values explicitly.
